When you need local-search data you're not just after a list of URLs—you want the exact business name, address, rating, and the surrounding PAA context that Google surfaces for a query like "best pizza in Austin, TX". Geekflare's Search endpoint (`POST https://api.geekflare.com/search`) gives you that in a single JSON payload:

* **Geo-targeting** works across more than 65,000 cities. Supplying `city: "Austin,Texas,United States"` (or any `City,Region,Country` string) returns the same SERP a local user would see, at the same 2-credit cost as a generic search.

* **Grounded AI answer** (`groundedAnswer: true`) adds an inline, citation-rich answer generated by Google's own LLM, costing **5 credits** total.  

All of these modes respect the same per-second request caps: **1 req/s** on the Free tier, **5 req/s** on Starter, **10 req/s** on Growth, **25 req/s** on Business, and up to **1,000 req/s** on Enterprise. The limits are expressed as *requests per second* (req/s) rather than concurrent connections, which simplifies capacity planning for batch jobs that run every night or for real-time micro-services that fire on demand.

From a reliability standpoint Geekflare has been bootstrapped since 2015, runs on Google Cloud Platform backed by Cloudflare's edge network, and advertises **99.9% uptime** across all its APIs. Over **21,000 businesses** already trust the platform, and user ratings sit at **4.9 average** (G2 4.8, Google 4.9, Product Hunt 5.0). Those numbers matter when you're feeding a rank-tracker that must stay online 24/7; a single 5xx outage would otherwise corrupt a day's worth of keyword data.

Finally, Geekflare's credit model is deliberately simple: each API call consumes a fixed number of credits, there are no hidden multipliers, and **failed 5xx requests are free**. Credits reset on the first of every billing cycle, so you never have to worry about roll-over balances inflating your bill unexpectedly.

## **Quickstart Implementation You Can Drop Into Your Repo**

Below are two minimal, production-ready snippets that hit the Search endpoint with the exact parameters you need for a local-business SERP request. Both examples request the full SERP JSON (`serp: true`) for a city-level query and demonstrate how to handle the credit-based response.

### **Python (using the official `geekflare-api` SDK)**

```python
# Install the SDK first:
# pip install geekflare-api

from geekflare_api import GeekflareClient

# Initialise the client – replace YOUR_API_KEY with your real key
client = GeekflareClient(api_key="YOUR_API_KEY")

# Build the request payload
payload = {
    "q": "best coffee shop",
    "city": "Portland,Oregon,United States",
    "device": "mobile",
    "serp": True,          # Get full Google SERP JSON
    "output": "json"       # Options: json, markdown, html
}

# Perform the search – this call costs 2 credits total
response = client.search(payload)

# Inspect the structured result
print("Credits used:", response['credits_used'])   # should be 2
print("Local pack entries:", response['data'].get('local_pack', []))
print("People Also Ask:", response['data'].get('paa', []))
```

### **Node.js (using the official `@geekflare/api-node` package)**

```js
// Install the SDK first:
// npm install @geekflare/api-node

const { GeekflareClient } = require("@geekflare/api-node");

// Initialise the client – replace YOUR_API_KEY with your real key
const client = new GeekflareClient({ apiKey: "YOUR_API_KEY" });

(async () => {
  const payload = {
    q: "plumbing services near me",
    city: "Manchester,England,United Kingdom",
    device: "desktop",
    serp: true,          // Full SERP JSON
    output: "json"
  };

  // This request costs 2 credits total
  const response = await client.search(payload);

  console.log("Credits used:", response.credits_used);
  console.log("Local pack:", response.data.local_pack);
  console.log("PAA:", response.data.paa);
})();
```

Both snippets rely on the same underlying endpoint (`POST https://api.geekflare.com/search`) and respect the 2-credit cost for a standard SERP query. If you need the raw HTML of the top result pages, simply add `"scrape": true` to the payload; the SDK will automatically adjust the credit accounting to **4 credits** for that call.

4. **Feature gaps** – Local-pack data, PAA, and Google AI Overviews are essential for local-search intelligence. If an API only returns organic URLs, you'll need a second service to fill the gaps, adding latency and cost.  
5. **Support & SLA expectations** – As usage grows, you need priority support and longer log retention for debugging. Geekflare's Business tier adds 90-day logs and priority email, a level of service many low-cost providers simply don't offer.
